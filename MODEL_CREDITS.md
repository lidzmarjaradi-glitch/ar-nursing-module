## Adding Credits to Your App

You can add model credits in several places:

### 1. In the Info Panel
Each model can show creator credit below the description.

### 2. In the Footer
Add a credits link in the footer of `index.html`:
```html
<footer>
    <p>© 2024 AR Clinical Skills | <a href="/credits.html">Model Credits</a></p>
</footer>
```

### 3. In a Dedicated Credits Page
Create `credits.html` listing all external resources used.

**Important**: Always respect creator licenses and give proper attribution!
