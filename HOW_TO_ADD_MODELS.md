## How to Add the Realistic Heart Model

### Step 1: Download from Sketchfab

1. Visit: https://sketchfab.com/3d-models/realistic-human-heart-3f8072336ce94d18b3d0d055a1ece089
2. Click **"Download 3D Model"** (you may need to create a free account)
3. Select format: **"glTF (embedded .gltf)"** (easiest option)
   - Alternative: **"glTF separate (.gltf + .bin + textures)"** for better quality
4. Download the ZIP file

### Step 2: Extract and Place Files

**Option A - Embedded GLTF (Simplest):**
```
ar-nursing-module/
└── public/
    └── models/
        └── heart/
            └── scene.gltf    (All-in-one file)
```

**Option B - Separate Files (Better quality):**
```
ar-nursing-module/
└── public/
    └── models/
        └── heart/
            ├── scene.gltf
            ├── scene.bin
            └── textures/
                ├── texture1.jpg
                ├── texture2.jpg
                └── ...
```

### Step 3: Verify File Structure

The folder structure should look like:
```
ar-nursing-module/
├── public/
│   ├── models/
│   │   └── heart/
│   │       └── scene.gltf
│   ├── ar-viewer.html
│   ├── index.html
│   └── handbook.html
├── server.js
└── package.json
```

### Step 4: Test It!

1. The server is already running at `http://localhost:3000`
2. Go to `http://localhost:3000/ar-viewer.html`
3. Click on **"Human Heart"**
4. The realistic model will load automatically!

## Troubleshooting

### Model doesn't load?
- **Check console**: Open browser DevTools (F12) → Console tab
- **Check path**: Make sure `scene.gltf` is at `/models/heart/scene.gltf`
- **Fallback**: If model fails, it automatically uses the procedural heart

### Model is too big/small?
Edit the scale in `ar-viewer.html`:
```javascript
const modelConfig = {
    heart: { type: 'external', path: '/models/heart/scene.gltf', scale: 1.0 },
    // Change scale to 0.5 for smaller, 2.0 for bigger
};
```

### Model has no textures?
- Use **"glTF embedded"** format (includes textures in one file)
- Or ensure all texture files are in the correct relative paths

## Adding More External Models

Want to add realistic lungs, brain, or kidney models? Follow the same pattern:

### Example: Adding Realistic Lungs

1. Download lungs model from Sketchfab (search: "realistic human lungs")
2. Place in: `public/models/lungs/scene.gltf`
3. Update config in `ar-viewer.html`:

```javascript
const modelConfig = {
    heart: { type: 'external', path: '/models/heart/scene.gltf', scale: 1.0 },
    lungs: { type: 'external', path: '/models/lungs/scene.gltf', scale: 1.0 },
    // ... other models
};
```
